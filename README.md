# Meu 1º Afinador Violão para Android

Downloads oficiais do app Meu 1º Afinador Violão.

## Baixar

Abra a aba **Releases** deste repositório e baixe o arquivo APK da versão mais recente.

## Instalar no Android

1. Baixe o arquivo APK pelo celular.
2. Abra o arquivo baixado.
3. Se o Android pedir permissão para instalar apps de fonte externa, permita para o navegador ou gerenciador de arquivos usado no download.
4. Conclua a instalação.

## Sobre o app

Meu 1º Afinador Violão ajuda iniciantes a afinar as cordas do violão com orientação visual simples e direta.

Recursos:

- Afinador para as 6 cordas do violão
- Detecção pelo microfone
- Orientação clara para apertar ou soltar a corda
- Indicação de corda afinada
- Guia visual das tarraxas
- Avanço automático para a próxima corda

## Privacidade

O app usa o microfone apenas para ouvir a corda do violão e calcular a afinação no próprio dispositivo. O áudio não é gravado, armazenado ou enviado para servidores.
