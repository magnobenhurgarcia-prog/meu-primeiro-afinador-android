# Meu 1º Afinador Violão v1.0.1

Atualização com tela de abertura.

## Novidades

- Adicionada capa de abertura do app.
- Ajustado splash inicial com a identidade visual do app.
- Mantidos o novo ícone, afinador por microfone e guia visual das tarraxas.

## Instalação

Baixe o arquivo APK desta release pelo celular Android e abra o arquivo para instalar.

Se você já instalou a versão `1.0.0`, esta versão deve instalar como atualização por cima.

Se o Android pedir permissão para instalar apps de fonte externa, habilite a permissão para o navegador ou gerenciador de arquivos usado no download.

## Privacidade

O app usa o microfone apenas para ouvir a corda do violão e calcular a afinação no próprio dispositivo. O áudio não é gravado, armazenado ou enviado para servidores.
